# HOLLOW SHIFT

A 3D mobile survival-horror night-watch game. You are the overnight security
guard at **Bramble Bear's Pizza Depot**. You have a chair, two doors, two hall
lights, a camera tablet and a finite amount of electricity. Survive from
12 AM to 6 AM, six times.

Single player is a faithful take on the classic office/camera/power loop.
Co-op free-roam is the next milestone.

> **Original work.** Every character, name, model, texture and sound in this
> repository is generated by this codebase. There are no third-party assets and
> nothing is copied from any existing game - only the *mechanics* are in the
> tradition of the genre.

## Stack

| Layer | Choice | Why |
| --- | --- | --- |
| Language | TypeScript 5 (strict) | Catches the class of bug that ships in a jam game |
| Renderer | three.js (WebGL2) | Runs on every phone made in the last six years, no store gate for testing |
| Build | Vite 7 | 2-second builds, instant HMR, ~157 KB gzipped output |
| Audio | Web Audio, fully synthesised | Zero download, original by construction, per-event pitch and pan |
| Storage | localStorage with in-memory fallback | Progress survives an app swipe; never throws in private mode |
| Tests | Vitest (sim) + Playwright (browser) | The rules are tested headless; the game is tested in a real browser |
| Packaging | PWA now, Capacitor shell for the stores | One codebase for web, Android and iOS |
| Multiplayer | Node + `ws`, server-authoritative (M4) | The whole simulation is already headless and seedable |

## Just play it

**[`hollow-shift.html`](hollow-shift.html) is the whole game in one file.**
Download it and open it - no install, no server, no build step. It works from
a phone's file manager, a USB stick, or any static host. 588 KB, no external
requests: every texture is drawn to a canvas and every sound is synthesised at
runtime, so there is nothing to fetch.

Regenerate it after a code change with `npm run build:single`.

## Running it

```bash
npm install
npm run dev        # http://localhost:5173 - open it on your phone over LAN
npm run build      # production bundle in dist/
npm test           # simulation unit tests + difficulty regression sweep
npm run balance    # prints the win-rate table for all six nights
npm run smoke      # drives the built game in Chromium, writes artifacts/*.png

npm run build:single   # regenerate the standalone hollow-shift.html
npm run smoke:single   # build it, then verify it over file:// as a player would
```

## How it plays

- **Doors** seal a doorway completely. Nothing walks through a closed shutter.
- **Hall lights** are hold-to-use and are the only way to see who is standing
  in a doorway before they come in.
- **The tablet** shows eleven cameras. It is also the only way to watch the
  fox's curtain and to freeze the bear - and it blinds you to the office.
- **Power** drains at one bar for existing plus one bar per active system.
  Everything you switch on shortens the night.
- **At 0%** the grid dies, the shutters spring open, and a music box starts.
  See below.

Each of the five characters plays by different rules - see
[docs/DESIGN.md](docs/DESIGN.md) for the full behaviour spec, and
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the module map.

## Power recovery (the blackout)

There is no flashlight in this game. Light always costs power. When the grid
dies you get one thing: a hand-crank breaker bolted under the desk.

1. Everything electrical stops. Shutters spring open, lights and tablet die,
   one battery LED stays on.
2. Bramble takes the doorway and starts a music box. The tune runs 9-22
   seconds, randomised. When it ends, so does your shift.
3. Hold the crank to build charge. Let go and the charge bleeds away.
4. Fill the bar and the breaker trips back in: you get a small reserve, your
   doors work again, and the lights coming on shove him back down the hall.
5. Every blackout in the same night costs more and pays less:
   95 / 142 / 214 / 321 / 481 charge (2.3s / 3.4s / 5.1s / 7.6s / 11.5s of
   cranking) for 22% / 14% / 9% / 6% / 4% of the grid back.
6. Cranking is loud. It removes 0.35s from the tune per second of cranking and
   makes the fox considerably braver.

Recovery buys minutes, never the night. Nobody else can land a kill in the
dark - the blackout is one readable duel, crank against music box - but they
all keep closing in while you crank, and they are standing in your open
doorways when the lights come back.

## Status

**Milestone 1 (single player) is complete and verified.** Six nights, five
characters, eleven cameras, power and blackout, save system, settings, 3D menu,
touch controls, four graphics presets. 22 unit tests, a 480-night balance
sweep, and a 20-check browser smoke run all pass - the smoke run passes against
both the multi-file build and the standalone `hollow-shift.html` loaded over
`file://`.

**Not built yet:** co-op multiplayer (unlock and menu entry are wired; the mode
itself says so on screen rather than pretending), and the Capacitor store
shells. See [docs/ROADMAP.md](docs/ROADMAP.md).
