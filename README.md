## Corn Field v1.01 (Roblox horror game)

`CornField.server.lua` is the whole game in one Script.
Put it in **ServerScriptService** in Roblox Studio and press Play.

- **Normal:** escape the Corn Field (find 3 symbols, enter the code, run out the gate).
- **Nightmare:** escape the barn, find the rusty key on the farm (watch out for the Farmer), call the police, unlock the gate and drive off in the police car.

Set `CONFIG.BadgeId`, `CONFIG.NightmareBadgeId` and `CONFIG.MonsterGamepassId` at the top once you make the badges and the 100 Robux game pass on create.roblox.com.
