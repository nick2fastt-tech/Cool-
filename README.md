## Corn Field (Roblox horror game)

`CornField.server.lua` is the whole game in one Script.
Put it in **ServerScriptService** in Roblox Studio and press Play.
Set `CONFIG.BadgeId` and `CONFIG.MonsterGamepassId` at the top once you make the badge and the 100 Robux game pass on create.roblox.com.
