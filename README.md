# Cool-

Browser games that run with no build step, no dependencies and no downloads —
open the file and play.

| Game | Play | What it is |
| --- | --- | --- |
| **T10 World** | [`t10/index.html`](t10/index.html) | A full 3D New York City life simulation. Wake up in your apartment, walk out, and live in the city — subway, jobs, weather, day/night, and the T10 command system. [Read more](t10/README.md) |
| **The Last Candle** | [`horror.html`](horror.html) | A single-file first-person horror crawl through a dark asylum. |

Both are built for phones first: touch joystick, drag to look, on-screen buttons.
